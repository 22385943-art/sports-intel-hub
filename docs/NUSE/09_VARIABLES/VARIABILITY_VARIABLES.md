# Variability Variables

## Purpose

This document defines every variable describing variability within the NBA Universal Simulation Engine (NUSE).

Within NUSE, variability represents the intrinsic fluctuation of basketball performance across possessions, games, seasons and careers.

Unlike uncertainty, which reflects incomplete knowledge, variability represents genuine differences in observed outcomes generated by the basketball process itself.

Variability is therefore an inherent property of the simulated system.

---

# 1. Core Principles

Variability is intrinsic.

Variability exists independently from uncertainty.

Variability differs across entities.

Variability evolves through time.

Variability SHALL propagate through every probabilistic simulation.

Variability SHALL remain measurable.

# Final Statement

Variability variables define the intrinsic dispersion of basketball performance within NUSE.

Rather than attributing every difference in observed outcomes to uncertainty, NUSE explicitly distinguishes natural performance variability from incomplete knowledge. This separation enables more accurate probabilistic simulation, more robust predictive modeling and clearer interpretation of basketball behavior across every level of the engine.
