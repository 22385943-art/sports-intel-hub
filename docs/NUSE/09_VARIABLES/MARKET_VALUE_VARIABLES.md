# Market Value Variables

## Purpose

This document defines every market value-related variable recognized by the NBA Universal Simulation Engine (NUSE).

Within NUSE, market value represents the league-wide perception of a player's worth at a specific moment in time.

Unlike intrinsic player value, market value is influenced by perception, reputation, media exposure, organizational demand, contract situations and recent performance.

Market value evolves continuously as information becomes available.

---

# 1. Core Principles

Market value is dynamic.

Market value is contextual.

Market value is perception-driven.

Market value is probabilistic.

Market value SHALL evolve continuously.

Market value SHALL remain distinguishable from intrinsic player value.

# Final Statement

Market value variables represent the perceived value of basketball assets throughout the NBA ecosystem.

Rather than assuming every franchise evaluates players identically, NUSE models market value as a dynamic perception generated by executives, coaches, media exposure, contractual circumstances, organizational demand and recent performance. This framework enables realistic trade negotiations, free agency behavior and asset valuation while preserving explainability and causal consistency throughout the simulation engine.
