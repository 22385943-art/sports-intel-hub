# NUSE Variables Index

## Purpose

This document defines the complete index of all variables used within the NBA Universal Simulation Engine (NUSE).

It does NOT define formulas.

It does NOT define implementations.

It ONLY defines the full universe of measurable, estimated, derived, latent, contextual, and simulated variables.

Every variable in the system MUST be declared here before it is used elsewhere.

---

# 1. Core Principle

All basketball reality in NUSE is represented through variables.

A variable is any measurable or estimable property that changes or influences change over time.

No variable may exist outside this index.

---

# 2. Variable Classification System

Every variable belongs to exactly one primary domain and one type.

# 10. VARIABLE RULES

- Every variable MUST belong to one domain
- Every variable MUST have a unique identifier
- No variable duplication is allowed
- No undefined variables may be used in other documents
- Latent variables MUST be explicitly estimated, never assumed
- Derived variables MUST be traceable to observable or latent inputs

---

# 11. FINAL STATEMENT

This document represents the complete canonical registry of all variables in the NUSE system.

All formulas, simulations, and predictions MUST exclusively use variables defined here.
